# Wallpaper Weather — DMS port v5

Faithful DMS shape of RR-CodeBase/omarchy-wallpaper-weather:

- composite plugin
- background service for wallpaper effects
- DankBar widget for status/control entry point
- DMS WeatherService for weather/location
- no Python, ImageMagick, curl, jq, or QtQuick.Particles

## Install

```bash
./install.sh
```

Then enable **Wallpaper Weather** in DMS Settings → Plugins and add **Wallpaper Weather** to DankBar.
